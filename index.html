    About

    I'm a Frontend Developer passionate about turning ideas and designs into responsive, interactive, and user-friendly web applications. My primary stack includes JavaScript, TypeScript, React.js, Next.js, HTML, CSS, and Tailwind CSS. I also have experience working on the backend with Node.js and Express.js, and working with databases such as PostgreSQL and MongoDB. I'm comfortable using Git and GitHub for version control and collaboration, and I have experience deploying applications with platforms such as Vercel, Render, and GitHub Pages. I'm always open to learning, collaborating, building something meaningful, and connecting with other developers and people in tech.
